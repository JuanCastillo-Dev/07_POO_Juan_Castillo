# Agenda de Contactos MVC

## Descripción
Este proyecto es una aplicación de consola para gestionar una agenda de contactos, desarrollada en Java 21 con Maven. El código sigue el patrón de arquitectura de software Modelo-Vista-Controlador (MVC) y cumple con el principio de responsabilidad única para mantener el proyecto ordenado y modular.

## Funcionalidades
1. **Registrar contacto**: Permite ingresar nuevos contactos por teclado con ID autoincremental.
2. **Listar contactos**: Muestra la lista completa de todos los contactos en el sistema.
3. **Buscar contacto**: Permite buscar contactos de forma interactiva por nombre o apellido (coincidencia parcial).
4. **Eliminar contacto**: Remueve un contacto de la agenda usando su ID de forma segura.
5. **Menú interactivo**: Consola con opciones del 1 al 5 para navegar fácilmente por la aplicación.
